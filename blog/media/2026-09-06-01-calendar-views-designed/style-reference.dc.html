PhD TV: Web Application Design System

Theme: 80s/90s Print TV Guide Aesthetic

Core Philosophy: Hard lines, high contrast, flat inks, and ruthless grid alignment. We embrace the visual language of cheap print media without sacrificing modern screen legibility.

1. Color Palette: The "Spot Ink" System

The palette mimics the four-color process and cheap spot inks used in weekly digests. Colors must always meet edge-to-edge or be separated by a black hairline. Rule: No gradients, no opacity fades, no soft shadows.

These components translate physical print habits into web UI patterns.

Rules & Borders: Structure is dictated by strict borders, not whitespace.
  • 1px #cdc4b0 (hairline) for cells.
  • 2px #141210 for regions (filter card, toolbar).
  • 6px double #141210 for major section breaks.
Corners: Hard, always. Boxes, bars, buttons, selects, chips, badges and cards use a 0 radius; print was cut and ruled square, and rounding reads as generic modern UI. The only round shapes are the starburst and small circular dot indicators (phone month view), which are shapes, not containers.

4. Anti-Patterns (What stays in the 90s)

To keep the app functional and modern, we intentionally abandon these print realities:

  • No Textures: Skip the paper grain, halftone dots, and misregistration blur. They read as noise on a screen and destroy legibility for small UI text.
  • No Micro-type: Print used 7pt type to save paper. We never drop below 11px, and keep body text at a comfortable 13–15px.
  • No Justified Columns: Print forced text to stretch edge-to-edge. We use ragged right to avoid awkward CSS text rivers.
  • No Color-on-Color: Red text on cyan backgrounds hurts accessibility. Text on a spot color must always be pure white or rich black.
